## Maintenance

- Add public entries only after confirming their exact source path.
- Preserve each document's status (proposal, implementation, test evidence, or adopted policy).
- Update `research-index.json`, `research.html`, and `sitemap.xml` when changing public navigation.
- Do not replace or silently reinterpret version-pinned machine-interface maps.
- Do not list private repositories, unpublished work, personal profiles, or restricted content.
